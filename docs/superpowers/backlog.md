the question is and what would answer it. EVERYTHING here is active by construction:
the standing rule (documentation rules; known-holes.md) is that closed backlog work is
deleted or narrowed in the closing PR, so a topic's presence means its question is
still open. Load ONE topic file; this index is the only thing meant to be read whole.

Quoted measurements inside topics are guarded by `tools/backlog.test.ts`; update
counts through that test, never by hand.
