Privacy Policy

Last updated: October 31, 2026

This policy covers the Tanks! browser game (the “game” or “app”), published at austinorphan.com/tanks/.

Summary

The game collects no data. The website that serves it reports page loads to Cloudflare Web Analytics; see “The website that hosts the game” below.

Data the game collects

Nothing. The game’s own code does not send any data over the network — no analytics, no telemetry, no API calls. All game data stays on your device.

Data the game stores

The game saves your progress and settings to your device using localStorage. If persistent storage is unavailable, the game uses an in-memory backup that expires when the page is closed. Data is organized into the following keys:

KeyContents
tanks.progress.v1Highest level cleared in the campaign
tanks.stats.v1Lifetime and per-attempt game statistics
tanks.stats.run.v1Game statistics for the campaign run in progress
tanks.run.v2Active campaign run: current level, remaining lives
tanks.custom.v1Chosen tank color and paint customization
tanks.settings.v1Player settings: sound mute and volume, touch control scheme and fire mode, device vibration and controller rumble preferences, controller layout (stick preset and rebound buttons, per controller type), motion/flash preference, interface scale, render quality preset, player color palette
tanks.achievements.v1Earned achievements
tanks.versus.v1Versus match setup: mode, player count, lives, friendly fire, arena, and which player slots are people or computer players (never which controller anyone uses)

tanks.settings.v1 replaces an older tanks.touch.v1 key. The first time you open this version of the game, any touch control settings saved under the old key are copied into the new one and the old key is deleted. The game never writes tanks.touch.v1 again; it is still accepted when importing a save file exported by an older version. An older tanks.run.v1 key, if present, is deleted unread when the game starts.

The settings key stores your preferences only. It never records which controllers are connected, their identifiers, their slot numbers, or which player is using which device.

This data is stored entirely in the browser and never leaves your device. It is scoped to the game’s origin: only the origin serving the game may access it, and it is unreachable by other sites.

If your browser cannot save data — for example in a private window, or with site storage blocked — the game still runs, and shows a brief on-screen note that settings will not be saved for that session.

In Settings, under Data, Reset stats sets your lifetime statistics and those of the campaign run in progress back to zero, and Reset progress clears your campaign progress (the levels unlocked in Level Select) and your earned achievements. Neither changes your settings or your tank customization. To remove everything the game has stored, clear this site’s data in your browser’s settings.

Developer sessions, opened with ?dev=1, keep their data under separate keys that start with tanks.dev., unless prodSave=1 asks for the keys above. With saveIo=1 as well, a developer session can export and import all of the keys above except tanks.versus.v1 as a single file, from the browser console. That is a development facility; the game has no button for it.

Audio & visuals

Sound is synthesized in real time. The game uses the Web Audio API to generate its sound effects and music. No audio files are downloaded from the network.

Graphics are drawn in real time with WebGL, through the Three.js library. The game downloads no external images, models or textures; its fonts and icons are served from the same site as the game.

The website that hosts the game

The game is served from austinorphan.com through Cloudflare. Like any web host, Cloudflare receives the standard details of every request it serves, such as the IP address and the browser’s user agent.

The site also uses Cloudflare Web Analytics. When a browser loads a page, Cloudflare adds a script (static.cloudflareinsights.com/beacon.min.js) that reports the page view and page-load timing to Cloudflare. The game’s own code does not include or call this script, and blocking it does not affect the game.

According to Cloudflare, Web Analytics does not use cookies or localStorage, does not fingerprint visitors, and does not track individuals across websites. Those are Cloudflare’s statements about its service, not findings of this project. Cloudflare’s privacy policy governs the data it receives.

Third-party services

The game’s own code has no third-party integrations. It does not use analytics or tracking services, advertising networks, social media plugins or buttons, external APIs, servers or CDNs, or cookies. The website that serves the game uses Cloudflare for hosting and Web Analytics, as described above.

The game does use a few browser APIs for local input only:

  • Gamepad API — reads connected controllers. Data stays on-device.
  • Web Vibrations API — provides haptic feedback on supported devices. No data is sent.

Children’s privacy

The game is designed for all ages. The game itself collects no personal information from any user, including children; what the hosting website’s Cloudflare services receive is described above. This policy is published as a matter of good practice, even though the game itself collects no personal data.

Changes to this policy

If the game’s privacy practices change, this policy will be updated.
