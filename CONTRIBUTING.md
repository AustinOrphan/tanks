# Contributing

Thank you for looking. Please read this before opening a pull request — the answer on code
is currently **no**, and that is about licensing rather than about the change.

> This file records the project's contribution policy. It is not legal advice.

## Code and asset contributions are not being accepted

The project is source-available under [PolyForm Shield 1.0.0](LICENSE), and the owner
retains the right to develop, license and distribute it commercially. Doing that requires
rights in every contribution that an ordinary pull request **does not grant** — in
particular the right to relicense the work and to use it commercially.

No contributor agreement exists yet, so there is no mechanism to obtain those rights. Until
one does, outside code and asset contributions cannot be accepted, and a pull request opened
under the repository license alone would not convey what the project needs. Opening one
anyway risks wasted effort, which is the reason this file is explicit rather than silent.

This is not a judgement about the contribution.

## What is welcome

- **Issue reports** — bugs, reproductions, crashes, platform problems.
- **Playtest feedback** — how something feels at normal speed, where the difficulty sits.
- **Questions and discussion** about behaviour, design or direction.

None of these require the rights above.

## If you want to use the code

`LICENSE` governs. In short — and the license text controls, not this summary — you may read
the code and experiment with it privately, but you may **not** use it to provide a competing
product. That holds whether the competing release is paid **or free**.

For anything the license does not permit, ask. The owner may grant exceptions, commercial
licenses or modding permissions separately, and separately granted written permission
overrides the default.
